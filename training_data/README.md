# Training data

This directory contains the SDOC hackathon Docker distribution copied from the recent Downloads ZIP.

- Archive: `sdoc-hackathon-docker/sdoc-hackathon-docker.zip`
- Extracted files: `sdoc-hackathon-docker/extracted/`
- Dataset documentation: `sdoc-hackathon-docker/extracted/data_v2/README.md`

The distribution includes the answer key at `extracted/data_v2/ground_truth.json`. Keep this GitHub repository private while that file is present.
